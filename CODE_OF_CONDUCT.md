# Code of Conduct

FaceWebChain is a learning and research project. Participants are expected to be respectful, constructive, and mindful of privacy.

Unwelcome behavior includes harassment, discrimination, threats, doxxing, sharing private biometric data, and using project discussions to target people. Maintainers may remove content or restrict participation when needed to keep the project safe and useful.

Report concerns privately to the repository maintainers rather than publishing personal information in an issue.
